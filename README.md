# Sales Form Automation

A web-based sales form built with **React** to automate data entry into Google Sheets. This tool was actively used by my team to streamline workflows and reduce manual input.

## Overview

Link: https://salesform-8jtqzuztm-derek-chens-projects-0fa289f3.vercel.app/

This project was designed to replace repetitive manual data entry with a simple, structured form that automatically sends submissions to a centralized Google Sheet.

The focus was on building something **practical and usable in a real environment**, not just a demo project. It improved efficiency and reduced errors for day-to-day team operations.

## Features

- Structured form for consistent sales data entry  
- Automatic submission to Google Sheets  
- Input validation to reduce errors  
- Clean and simple UI for fast usage  
- Real-time usage by a team environment  

## Tech Stack

- React  
- JavaScript (ES6+)  
- HTML / CSS (Vanilla)  
- Google Sheets API / integration  

## Key Contributions

- Designed and built the front-end form using React  
- Integrated form submissions with Google Sheets  
- Improved team workflow by reducing manual entry  
- Ensured reliability for repeated daily use  

## Challenges

- Connecting a front-end application to Google Sheets  
- Handling authentication and API communication  
- Ensuring data consistency and formatting  
- Building a UI that is fast and easy to use under real conditions  

## Impact

- Reduced time spent on manual data entry  
- Improved data consistency across the team  
- Adopted and used by the entire team in daily operations  

## Development Notes

This project emphasized **real-world usability over complexity**. The goal was to solve a concrete problem efficiently rather than over-engineer the solution.

## Reflection

This was one of my first projects that delivered direct value in a team setting. It reinforced the importance of building tools that people actually use, and not just focusing on technical complexity.
